# Shoal CLI — Hermes Context

Shoal is a tmux+SQLite orchestration control plane for parallel AI coding agents.

## Key entry points
- `src/shoal/services/lifecycle.py` — session create/fork/kill/reconcile (single orchestrator)
- `src/shoal/services/mcp_shoal_server.py` — 47 MCP tools exposed to agents
- `src/shoal/core/db.py` — SQLite schema (sessions, incidents, status_transitions)
- `src/shoal/core/journal.py` — session journals + outcome capture

## Conventions
- All I/O is async; subprocess calls use `asyncio.to_thread()`
- Conventional commits: `feat|fix|docs|style|refactor|perf|test|chore(scope): description`
- Run `just ci` before committing (lint → typecheck → test)
- mypy --strict enforced; all functions need type hints

## Active features (2026-04)
- Session collision detection: `check_file_collisions` MCP tool
- Session outcome capture: `capture_session_outcome` MCP tool + `SessionOutcome` in journal.py
- Format-on-write hook: `integrations/hooks/claude_format_on_write.sh`
